# Copper Golem Mod for Mineclonia

This mod adds the Copper Golem to Mineclonia.

## How to Install
1. Copy the `copper_golem` folder to your Minetest `mods` directory.
2. Enable the mod in your Mineclonia world.

## How to Spawn
Place a **Block of Copper** (`mcl_copper:copper_block`) and put a **Lightning Rod** (`mcl_copper:lightning_rod`) on top of it.

## Assets
This mod uses a scaled-down version of the **Iron Golem** model (`mcl_mobs_iron_golem.b3d`) by default.

- **Texture**: You should provide a copper-colored texture in `textures/mcl_mobs_copper_golem.png`.
- If you don't provide one, it might appear with a default or missing texture.
